# ROFLA Patisserie — نظام إدارة المحل والمصنع

**النسخة:** V37 — واجهة تشغيل مبسطة للمحل والمصنع

**تشغيل النظام:** https://ibrahimmandor-design.github.io/rofla-calculator/management/

## ماذا يدير النظام؟

نظام واحد لمتابعة دورة الصنف والخامة من أول شراء حتى البيع والرصيد المتبقي:

**اشترينا ← استلمنا ← خزّنا ← استخدمنا في الإنتاج ← أنتجنا ← بعنا ← حسبنا التكلفة والمكسب.**

### 1. المشتريات والموردون

أنواع الشراء منفصلة وواضحة، مع قوائم اختيار تتبدل حسب نوع الشراء في الشراء السريع وفاتورة الشراء:

- **خامات تدخل في الوصفات:** دقيق، سميد، سكر، سمن، زيوت، زبدة، ألبان، شوكولاتة، مكسرات، فواكه، إضافات، ومواد التغليف التي تدخل في تكلفة المنتج.
- **مستلزمات تشغيل:** منظفات، مطهرات، قفازات، غاز تشغيل، وأدوات النظافة والسلامة.
- **أصناف جاهزة للبيع:** أي منتج نشتريه من مورد لإعادة بيعه كما هو.

تسجيل المورد، الفاتورة أو الإيصال، الكمية، الوحدة، إجمالي السعر، المدفوع، الآجل، حد إعادة الطلب، وصلاحية الخامات عند الحاجة. قوائم الأصناف والموردين تقترح الأسماء المسجلة وتقبل كتابة اسم جديد.

### 2. التصنيع والتشغيلات

- كتالوج الأصناف مقسم إلى شرقي، غربي، مخبوزات، مكسرات وشوكولاتة، ومشروبات.
- كل الأصناف الـ126 مصنفة حالياً «تصنيع داخل المحل» حسب توجيه المالك.
- لكل صنف وصفة قابلة للإضافة والتعديل، مع خصم الخامات وتسجيل الناتج الصالح للبيع والبواقي والهالك وتكلفة التشغيلة.
- لا توجد مقادير وصفات فعلية مسجلة حتى الآن؛ لا يتم اختراع وصفات أو كميات.

### 3. سجل دورة الصنف والخامة

يظهر في لوحة المتابعة، حتى قبل أول حركة، كتالوج الأصناف والخامات ومستلزمات التشغيل بأرصدة افتتاحية صفرية. ويعرض لكل صنف:

- أول شراء، عدد فواتير الشراء، الموردون، الكمية وقيمة المشتريات ومتوسط تكلفة الشراء للوحدة.
- مرات تسجيل الإنتاج، دفعات الإنتاج، الناتج الصالح وتكلفة الإنتاج المباشرة.
- فواتير البيع، إجمالي المباع، المرتجعات، صافي المباع ومتوسط سعر البيع.
- استهلاك الإنتاج، الرصيد الحالي، تكلفة الوحدة الحالية وقيمة المخزون المتبقي وصافي قيمة البيع.

لا يتم تقدير أي كمية أو سعر غير مسجل.

### 4. البيع والعملاء

قنوات البيع تشمل المحل، التوصيل، التطبيقات، الطلبات الخاصة، الجملة، الكافيهات والمطاعم، القاعات والمناسبات، الشركات، مع إمكانية كتابة قناة مخصصة. يشمل النظام فواتير البيع، التحصيل، الآجل، أرصدة العملاء والمرتجعات.

### 5. المصروفات الثابتة والتكلفة الكاملة

يمكن تسجيل الإيجار والرواتب والكهرباء والمياه والغاز والإنترنت والصيانة وغيرها كمصروفات متكررة، مع إمكانية كتابة نوع مخصص.

- التقرير الشهري يضم الاستحقاقات الثابتة المسجلة، حتى لو لم يتم تجهيز فاتورة السداد بعد.
- التقرير اليومي يوزع المصروف الثابت الشهري على أيام الشهر.
- نصيب كل صنف ونصيب الوحدة المباعة من المصاريف الثابتة يظهر منفصلاً عن المصاريف الأخرى.
- طريقة التوزيع قابلة للاختيار: حسب التكلفة المباشرة، أو صافي المبيعات، أو عدد الوحدات عند تقارب وحدات الأصناف.
- يعرض التقرير التكلفة الكاملة وربح الصنف بعد توزيع المصاريف.

هذا توزيع محاسبي إداري، وليس قياساً مباشراً لساعات العمالة أو استهلاك الكهرباء لكل منتج.

### 6. المتابعة والتقارير

تنبيهات نقص المخزون والصلاحية، مقارنة أسعار الموردين، مديونيات الموردين والعملاء، حركة الخزنة، إقفال اليوم، وسجل مراجعة التغييرات، وتقارير يومية وشهرية.

### 7. قوائم قابلة للاختيار والكتابة

الخامات، الأصناف، الموردون، العملاء، قنوات البيع، أقسام الأصناف وأنواع المصروفات تدعم الاختيار من الاقتراحات أو كتابة قيمة جديدة عند عدم وجودها.

## حالة البيانات الفعلية عند التسليم

تمت مراجعة قاعدة بيانات ROFLA الفعلية:

| البيان | الحالة |
|---|---:|
| أصناف الكتالوج | 126 |
| أصناف تصنيع داخل المحل | 126 |
| أصناف شراء جاهز | 0 |
| وصفات بمقادير فعلية | 0 |
| فواتير شراء فعلية | 0 |
| تشغيلات إنتاج فعلية | 0 |
| مبيعات ومرتجعات فعلية | 0 |
| مصروفات واستحقاقات فعلية | 0 |

تم تحديث تصنيف الأصناف الـ126 إلى «تصنيع داخل المحل» وفق طلب المالك. لم تتم إضافة مشتريات أو أسعار أو أرصدة أو وصفات أو مبيعات تجريبية. يجب إدخال المقادير الفعلية لكل وصفة ورصيد المخزون الافتتاحي الحقيقي قبل الاعتماد على تكلفة الإنتاج والربح.


## مراجعة الواجهة V37

- تبسيط شاشة الشراء لتسجيل خامة أو مستلزم أو علبة شوكولاتة جاهزة، مع مكان الشراء والمبلغ المدفوع.
- إخفاء إدخال الفواتير متعددة الأصناف والبيع متعدد الأصناف عن الاستخدام اليومي لتقليل خطوات الشيف والكاشير.
- فصل جهات التوريد المحتملة للكافيهات والمطاعم وقاعات الأفراح في قسم إدارة مستقل.
- إبقاء جرد الدرج وإقفال اليوم متاحين من شاشة النقدية.
- لا يُطلب رقم فاتورة في التشغيل اليومي. إرفاق صورة الفاتورة لم يُفعّل بعد.
