# ملف تجهيز التشغيل الحقيقي — ROFLA

**الغرض:** جمع البيانات الموثقة قبل إدخالها إلى النظام. هذا ملف تجهيز وتدقيق، وليس وصفات أو أسعاراً مفترضة.

## 1. سياسة التشغيل المعتمدة
- داخل رفلا: تصنيع الحلويات الشرقية والمخبوزات فقط.
- من الموردين: الحلويات الغربية، الجاتوه والتورت، الشوكولاتة الجاهزة، وأي قطعة جاهزة لإعادة البيع.
- مستلزمات التشغيل (منظفات، مطهرات، قفازات، أدوات نظافة وسلامة وغاز تشغيل) تُسجل منفصلة عن خامات الوصفات.
- مخزون واحد مشترك للمحل والمطبخ في النسخة الحالية؛ لا تقسّم الكميات على مخزنين داخل النظام.

## 7. نموذج الجرد الافتتاحي
| الصنف/الخامة | النوع | وحدة المخزون | الكمية بعد العد/الوزن | تكلفة الوحدة المثبتة | القيمة | الصلاحية | موقع التخزين |
|---|---|---|---:|---:|---:|---|---|
| | خامة / مستلزم / جاهز | | | | | | |

- عد أو زن الموجود فعلياً في تاريخ بداية التشغيل.
- افصل العبوات الجزئية والمفتوحة عند اختلاف الكمية أو الصلاحية.
- سجل العبوات الجزئية بالوزن الفعلي لا بعدد عبوات تقديري.
- لا تستخدم سعر المنافس لتقييم رصيد المخزون.
- اعتمد الجرد بتوقيع المدير والشيف/مسؤول المخزن قبل ترحيله.

## 9. خطة تجربة جهازين
1. صدّر نسخة احتياطية قبل الاختبار.
2. على جهاز المالك: سجل الدخول وتأكد من ظهور الكتالوج.
3. على جهاز المحل المعتمد: سجل الدخول بالحساب نفسه، ثم حدّث البيانات من السحابة.
4. لا تنفذ معاملة مالية تجريبية على قاعدة المحل. استخدم بيئة اختبار منفصلة لاختبار السيناريوهات.
5. إذا أجريت تغيير إعداد غير مالي بموافقة المالك، تحقق من ظهوره على الجهاز الثاني بعد دورة التحديث (كل 30 ثانية تقريباً).
6. سجّل التاريخ والجهازين والنتيجة وأي رسالة خطأ.

## 10. النسخ الاحتياطي والاستعادة
- صدّر نسخة JSON مؤرخة قبل بدء العمل وكل يوم تشغيل.
- خزّن النسخة في مكان خاص بالمالك؛ الملف غير مشفر وقد يحتوي بيانات العملاء والحركة المالية.
- جرّب الاستعادة على متصفح/بيئة منفصلة لا تتصل بقاعدة الإنتاج.
- قارن عدد الأصناف والحركات والأرصدة قبل وبعد الاستعادة.
- لا تستعد نسخة فوق بيانات حقيقية أثناء العمل، ولا تشارك الملف مع العاملين.

## 11. روتين الفريق
**الشيف:** يراجع الخامات والوحدات والرصيد قبل الإنتاج؛ وبعد انتهاء التشغيلة يسجل الاستهلاك الفعلي، الناتج الصالح، البواقي والهالك.

**الكاشير:** يسجل كل بيع فور حدوثه، قناة البيع ووسيلة التحصيل، والعميل إذا كان البيع آجلاً، ويربط المرتجع بالفاتورة الأصلية متى أمكن.

**مسؤول الاستلام:** يطابق الصنف والكمية والوحدة والسعر مع البضاعة والفاتورة، ويفصل الخامات عن مستلزمات التشغيل والجاهز.

**المدير:** يعتمد الموردين والوصفات والجرد والأسعار والمصاريف، ويراجع نهاية اليوم والآجل والنقدية والتنبيهات.

> الوضع اليومي المبسط ليس نظام صلاحيات. الحساب المشترك لا يمنع الشيف أو الكاشير تقنياً من فتح أدوات الإدارة؛ لا تمنح دخول النظام إلا للأشخاص والأجهزة المصرح بها.

- [ ] اعتماد الموردين ومستندات الأسعار.
- [ ] إدخال الجرد الافتتاحي بعد العد والوزن.
- [ ] اعتماد وصفات الشرقي والمخبوزات بعد وزن الخامات والناتج.
- [ ] إدخال المصروفات الثابتة والمتكررة.
- [ ] اعتماد أسعار البيع بعد مراجعة التكلفة الكاملة.
- [ ] تدريب الشيف والكاشير ومسؤول الاستلام والمدير.
- [ ] تنفيذ إقفال تجريبي على بيئة اختبار.

**الحالة:** الاختبار الآلي ناجح؛ اعتماد التشغيل الواقعي مشروط بإكمال البنود أعلاه.
